 Data Visualization Dashboards

This repository contains multiple Data Visualization dashboards developed using Tableau and Microsoft Power BI. Each dashboard focuses on a different area of analysis and is designed to present specific insights clearly and effectively.

Data Preparation:

Python is used to clean and preprocess the datasets before they are used in Tableau and Power BI. This helps remove unnecessary, inconsistent, or irrelevant data so that it does not affect or overcrowd the dashboards and ensures accurate and meaningful visualizations.

Dashboards

The repository includes multiple dashboards, with each dashboard focusing on a different area, set of KPIs, and analytical requirements.

Tools Used

- Python – Data Cleaning & Preprocessing
- Tableau – Dashboard Development & Visualization
- Microsoft Power BI – Dashboard Development & Visualization
